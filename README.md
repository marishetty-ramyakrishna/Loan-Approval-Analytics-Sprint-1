# Loan Approval Analytics – Sprint 1

## Overview

This repository contains Sprint 1 of the **Loan Approval Analytics** project completed as part of my Data Science training at **Innomatics Research Labs**.

The main objective of Sprint 1 is to understand the loan application dataset, perform data cleaning and validation, and prepare a clean, structured, and analysis-ready dataset for the upcoming analytical stages.

## Sprint 1 Objectives

- Understand the business problem and dataset
- Explore the structure of the dataset
- Identify numerical and categorical features
- Analyze missing values and duplicate records
- Check data types and data quality
- Handle data inconsistencies and invalid values
- Perform outlier analysis
- Validate the cleaned dataset
- Prepare the final cleaned dataset for further analysis

## Dataset

The project uses a loan application dataset containing information about applicants, their financial characteristics, loan details, and loan approval status.

The target variable is:

- `Loan_Status`

## Data Cleaning & Preparation

The dataset was cleaned and prepared by:

- Checking dataset dimensions and structure
- Identifying missing values
- Handling missing values appropriately
- Checking duplicate records
- Reviewing data types
- Checking categorical values for inconsistencies
- Identifying potential outliers
- Validating the final dataset

The final cleaned dataset is included in this repository as:

`loan_cleaned_final.csv`
